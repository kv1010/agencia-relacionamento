1. O QUE E O PROGRAMA
---------------------
Aplicacao em Java, de linha de comando, que le os cadastros de candidatos de uma
agencia de relacionamento (arquivo candidatos.txt) e identifica os potenciais
companheiros de cada candidato. O usuario escolhe as tarefas por um menu. Tambem e
possivel cadastrar novos candidatos, listar todos e abrir o perfil de cada um para
ver e alterar seus dados.

2. REQUISITOS
-------------
- Java JDK instalado (comandos javac e java disponiveis no terminal).
- Versao usada no desenvolvimento: "21.0.12.1" 2026-08-18 LTS
- O codigo tambem foi compilado e testado com OpenJDK 21.

4. COMO COMPILAR
----------------
Na pasta do projeto (a que contem a pasta src), execute:

    javac -d bin src/tad/*.java src/app/*.java

Os arquivos compilados ficam na pasta bin.

5. COMO GERAR O ARQUIVO DE CANDIDATOS (programa auxiliar)
---------------------------------------------------------
    java -cp bin app.GeradorCandidatos [quantidade] [arquivo de nomes] [arquivo de saida]

Exemplos:
    java -cp bin app.GeradorCandidatos (30 candidatos, nomes.txt -> candidatos.txt)
    java -cp bin app.GeradorCandidatos 200 nomes.txt candidatos.txt

O gerador sorteia o estado entre MG, SP e RJ (poucos estados, para facilitar a
formacao de pares), o sexo (F ou M), o sexo de interesse (F, M ou I) e de 1 a 8
areas de interesse sem repeticao. O arquivo de nomes deve ter um nome por linha.

6. COMO EXECUTAR A APLICACAO
----------------------------
    java -cp bin app.Main [arquivo]

Se nenhum arquivo for informado, o programa le o candidatos.txt da pasta atual.
Exemplo com um arquivo especifico:
    java -cp bin app.Main candidatos.txt

Ao iniciar, o programa informa quantos candidatos foram carregados e mostra o menu:

    1 - Inserir/atualizar o grau de interesse e calcular os pares
    2 - Imprimir os potenciais companheiros de um candidato
    3 - Imprimir os K candidatos com mais companheiros
    4 - Imprimir candidatos sem nenhum companheiro
    5 - Imprimir candidatos com interesse em uma area
    6 - Imprimir candidatos que residem em um estado
    7 - Cadastrar um novo candidato
    8 - Imprimir todos os candidatos
    9 - Abrir o perfil de um candidato (ver e alterar dados)
    0 - Sair

IMPORTANTE: execute a opcao 1 antes das opcoes 2, 3 e 4. Elas dependem dos pares
calculados na opcao 1. As opcoes 5 a 9 podem ser usadas a qualquer momento.
Sempre que um candidato e cadastrado ou alterado, os pares calculados deixam de valer
e a opcao 1 deve ser executada de novo.

Em todo pedido de informacao o programa mostra antes as opcoes validas (lista de
candidatos com id, estados cadastrados, codigos das areas, faixa do grau e de K).

7. COMO USAR CADA OPCAO
-----------------------
Opcao 1 - Mostra o grau atual e a faixa possivel (0 a 15, a soma de todos os pesos).
          Digite o grau de interesse desejado (inteiro maior ou igual a zero, por
          exemplo 6). O programa recalcula os potenciais companheiros de todos os
          candidatos. Pode ser repetida com outro grau a qualquer momento.

Opcao 2 - O programa lista id e nome de todos os candidatos; digite o id do candidato
          (de 0 ate N-1). Imprime o numero de potenciais companheiros e seus nomes.

Opcao 3 - Digite K (de 1 ate o total de candidatos, que e mostrado). O programa
          imprime os K candidatos com mais companheiros. Em caso de empate vence o
          menor id. Se K for maior que o total, imprime todos.

Opcao 4 - Nao pede dados. Imprime id e nome dos candidatos sem nenhum companheiro.

Opcao 5 - Digite o codigo da area (1 a 8, listados na tela). Imprime id e nome dos
          candidatos que tem interesse nela.

Opcao 6 - O programa mostra os estados cadastrados; digite a sigla do estado
          (maiusculas ou minusculas). Imprime id e nome dos candidatos que residem nele.

Opcao 7 - Cadastra um novo candidato. Pede nome, estado, sexo (F/M), sexo do potencial
          companheiro (F/M/I) e areas de interesse (codigos separados por espaco).
          Antes de pedir o estado, mostra os estados cadastrados. Se a sigla digitada
          ainda nao existe, o programa avisa, cadastra o estado junto com o candidato
          e mostra a lista de estados atualizada. O candidato recebe o proximo id e fica
          so na memoria (o candidatos.txt nao e alterado).

Opcao 8 - Imprime todos os candidatos (id, nome, estado, sexos e areas).

Opcao 9 - Lista id e nome dos candidatos e pede o id. Abre o perfil do candidato com
          todos os dados e um menu proprio:
              1 - Alterar dados do candidato
              2 - Ver potenciais companheiros
              0 - Voltar ao menu principal
          Na alteracao o menu continua aberto depois de cada campo alterado (nome,
          estado, sexo, sexo do potencial companheiro, areas de interesse), mostrando
          os dados atualizados, ate o usuario escolher 0 (concluir alteracoes).
          Um estado novo digitado na alteracao tambem e cadastrado e listado.

Opcao 0 - Encerra o programa.

Codigos das areas: 1-ESPORTES 2-ARTES 3-MUSICA 4-CINEMA 5-TECNOLOGIA 6-ANIMAIS
7-GASTRONOMIA 8-CIENCIAS

8. REGRAS PARA DOIS CANDIDATOS SEREM POTENCIAIS COMPANHEIROS
-------------------------------------------------------------
Os tres criterios precisam ser verdadeiros ao mesmo tempo:
a) Moram no mesmo estado.

b) A orientacao e mutua: o sexo de cada um atende ao sexo de interesse do outro.
   O valor I (qualquer sexo) aceita todos.
   
c) O grau de interesse em comum e maior ou igual ao grau digitado na opcao 1.
   O grau em comum e a soma dos pesos das areas que os dois tem em comum:
       peso 1: ESPORTES, MUSICA, CINEMA
       peso 2: ARTES, ANIMAIS, GASTRONOMIA
       peso 3: TECNOLOGIA, CIENCIAS
Como a regra vale para os dois lados, a relacao e simetrica.

10. COMO EXECUTAR OS TESTES
---------------------------
    java -cp bin tad.TesteListaEncadeada
    java -cp bin tad.TesteLista
    java -cp bin tad.TesteCandidato
    java -cp bin app.TesteLeitor candidatos.txt

Cada teste imprime os resultados na tela; o resultado esperado de cada linha esta
indicado em comentario no codigo do teste.

11. OBSERVACOES
---------------
- O programa le o arquivo pelo caminho informado; se o arquivo nao existir ou estiver
  fora do formato, uma mensagem de erro e exibida e o programa termina.
- Candidatos cadastrados ou alterados pelo menu valem so ate o programa fechar; o
  candidatos.txt nao e modificado.
- Com muitos candidatos a opcao 1 fica mais lenta, pois as listas sao acessadas por
  posicao: com 300 candidatos leva menos de 1 segundo; com 2000, mais de 20 segundos.
